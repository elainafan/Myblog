## D
题目大意：你有 $n$ 个赌场，编号从 $1$ 到 $n$。每个赌场由三个整数描述：$l_i$、$r_i$ 和 $real_i$（$l_i \le real_i \le r_i$）。你最初有 $k$ 枚硬币。你只有在当前硬币数 $x$ 满足 $l_i \le x \le r_i$ 时，才能在第 $i$ 个赌场玩。玩完后，你的硬币数会变为 $real_i$。你可以以任意顺序访问这些赌场，并且不要求必须访问所有赌场。

数据范围：$1 \le t \le 10^4$，$1 \le n \le 10^5$，$0 \le k \le 10^9$，$0 \le l_i \le real_i \le r_i \le 10^9$，$\sum n \le 10^5$。
